# SAMAP DICOM Packager
Compress images, delete tags, extract patient data and pack in zip file

## Features
- Delete DICOM Private Tags
- Extract & Save DICOM Patient Data
- Delete DICOM Patient Data
- Extract & Save DICOM Useful Tags (Study Related Tags)
- Recompress DICOM Images (both lossless & lossy)
- ZIP DICOM Images (deflate zip)
- ~~Extract package stats (compression ratio, frames, size, patient data & etc)~~
